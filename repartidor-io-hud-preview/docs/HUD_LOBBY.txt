HUD LOBBY - REFERENCIA ACTUAL

Este archivo describe la interfaz actual del lobby.
No contiene codigo. Solo resume que muestra cada bloque y en que zona de la pantalla conviene vivir.

NOTA GENERAL
- En lobby no se muestra el HUD de carrera.
- El lobby actual funciona como pantalla de entrada, lista de jugadores y control de inicio.
- La jerarquia visual actual es centro de pantalla, con apoyo de un input DOM en la parte baja central.

1. FONDO / LOBBY BACKDROP
Que es:
- Un fondo oscuro que tapa la pantalla de juego para dejar claro que aun no empieza la partida.

Informacion que aporta:
- No muestra datos numericos.
- Su funcion es separar visualmente lobby vs partida.

Ubicacion en pantalla:
- Pantalla completa.

2. TITULO PRINCIPAL
Texto actual:
- "Sala Repartidor.io"

Informacion que aporta:
- Identidad de la pantalla.
- Deja claro que el jugador esta dentro de la sala previa a la partida.

Ubicacion en pantalla:
- Parte superior central.
- Debe ser el primer elemento visible del lobby.

3. SUBTITULO DE ESTADO
Texto actual variable:
- "Esperando jugadores"
- "Conectados: X/4 | Maximo 4 jugadores"

Informacion que aporta:
- Numero de jugadores conectados.
- Capacidad maxima de la sala.
- Estado general del lobby.

Ubicacion en pantalla:
- Debajo del titulo principal, centrado.

4. LISTA DE JUGADORES
Contenido actual:
- Lista vertical con los nombres conectados.
- Marca al host con "(Host)".
- Si aun no hay conexion del jugador local, muestra un mensaje de entrada.

Informacion que aporta:
- Orden visible de jugadores presentes.
- Identifica quien es host.
- Hace evidente si la sala esta vacia o ya esta lista.

Ubicacion en pantalla:
- Zona central.
- Debe ser el bloque principal del lobby debajo del subtitulo.

5. MENSAJE DE LOBBY
Contenido actual variable:
- "Escribe un username corto y presiona Entrar."
- "Eres host. Presiona PLAY para iniciar."
- "Esperando que el host inicie la partida..."
- "Conectando sala..."

Informacion que aporta:
- Instruccion principal del momento.
- Feedback de estado para el jugador local.

Ubicacion en pantalla:
- Parte baja central, arriba del boton PLAY.
- Debe estar cerca de la accion principal para que el mensaje se entienda rapido.

6. BLOQUE DE NOMBRE
Elementos actuales:
- Input de texto.
- Boton "Entrar".

Informacion que aporta:
- Permite capturar el nombre del jugador.
- El input acepta cualquier tecla cuando esta en foco.
- Mientras conecta, el boton cambia a "Conectando...".

Ubicacion en pantalla:
- Centro inferior, aproximadamente al 74 por ciento de alto de pantalla.
- Debe vivir debajo de la lista de jugadores y arriba del borde inferior.

7. BOTON PLAY
Texto actual:
- "PLAY"

Informacion que aporta:
- Accion para iniciar la partida.
- Solo debe estar visible y activo para el host cuando ya puede iniciar.

Ubicacion en pantalla:
- Parte inferior central.
- Debe ser la accion dominante del lobby cuando el host ya esta listo.

8. BANNER DE ESTADO GLOBAL
Contenido actual variable:
- Mensajes cortos de estado y feedback.

Informacion que aporta:
- Avisos temporales del sistema.
- Puede reutilizarse tanto en lobby como en partida.

Ubicacion en pantalla:
- Parte superior central.
- Debe usarse como aviso temporal, no como informacion persistente.

RESUMEN DE LAYOUT DEL LOBBY
- Arriba centro: titulo y subtitulo.
- Centro: lista de jugadores.
- Centro inferior: input de nombre y boton Entrar.
- Abajo centro: mensaje de estado y boton PLAY.
- Arriba centro: banner temporal cuando haga falta.

NOTAS DE DISENO PARA FUTURO REDISENO
- El lobby ya esta bastante centrado y claro.
- La prioridad visual correcta es: titulo -> jugadores -> accion principal.
- No conviene mezclar aqui widgets de carrera, clima, objetos o minimapa.
