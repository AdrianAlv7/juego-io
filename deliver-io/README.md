# Deliver.io

Proyecto activo del juego.

## Como correr

```bash
npm install
npm run dev:server
npm run dev
```

Cliente:

```text
http://localhost:5173
```

## Areas principales

- `src/scenes/gameScene/`
- `src/ui/`
- `src/network/`
- `src/garage/`
- `server/index.js`
